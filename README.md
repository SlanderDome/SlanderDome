# 💫 About Me:
I design and build backend and full-stack systems, with a focus on real-time, event-driven architectures, API design and containerised deployment. My work includes server-authoritative systems, where the backend manages application state and validates client actions.<br><br>My technical interests span WebSocket-based multiplayer engines, AI-assisted applications integrating multimodal models with REST APIs, client-side data processing and developer tooling for container workflows.<br><br>Current work: [Judgement](https://github.com/SlanderDome/Judgement), [Foliage Care](https://github.com/SlanderDome/Foliage_Care), [ForgeDeploy](https://github.com/SlanderDome/ForgeDeploy) and [Reconcile](https://github.com/SlanderDome/Reconcile).
